# Asteroids Game – Visual Basic 6 Implementation

## Project Overview
This repository contains a fully implemented version of the classic Asteroids arcade game, developed using Visual Basic 6 (VB6). The game includes:

- Player-controlled movement and shooting
- Asteroid spawning and destruction
- Collision detection
- Scoring system
- Game state management (start, play, game over)

The project demonstrates core programming concepts such as modular design, event-driven programming, and object interaction within a graphical environment.

## Repository Contents
The final working version of the game includes the following files:

- `ASTEROIDS.vbp` – Visual Basic project file
- `Module3.bas` – Core game logic and shared procedures
- `frmGame3.frm` – Main game form
- `frmGame3.frx` – Resource file for the game form
- `frmStart3.frm` – Start/menu screen form
- `frmStart3.frx` – Resource file for the start form

## How to Run the Game
1. Open `ASTEROIDS.vbp` in Visual Basic 6.0.
2. Ensure all the above files are located in the same directory.
3. Click **Run** in the VB6 IDE.
4. Play the game using the keyboard controls defined within the game.

## Key Concepts Demonstrated
- Event-driven programming
- Collision detection and physics-based interactions
- State management for menus, gameplay, and scoring
- Modular code design with reusable procedures
- Working with graphical elements and resource files

This project highlights the ability to take a partially completed starter codebase and develop it into a complete, interactive application. It demonstrates problem-solving, attention to detail, and logical programming skills transferable to other software development projects.
